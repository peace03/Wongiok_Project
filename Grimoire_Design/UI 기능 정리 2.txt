UI 기능 정리


1. 인트로 화면
 - 예정 없음


2. 이용약관 및 자동 저장 안내
 - 예정 없음


3. 타이틀 화면
 - 예정 없음


4. 메인 화면 = 타이틀 화면
 a. 버튼 공용
	- 마우스 오버 효과
	- 마우스 오버 사운드
 b. 새로운 게임 버튼
	- 클릭 시 기존 저장 파일의 존재 유무 확인
	- if 저장 파일 존재 O
		ㄴ파일 덮어쓰기 확인 팝업 노출
			a. 확인 버튼
				- 기존 저장 파일을 지우고 새로운 게임 저장 파일 생성
				- 파일 덮어쓰기 확인 팝업 닫힘
				- 로딩 화면으로 이동
			b. 취소 버튼
				- 파일 덮어쓰기 확인 팝업이 닫힘
	- if 저장 파일 존재 X
		ㄴ새로운 게임 저장 파일 생성
		ㄴ로딩 화면으로 이동
 c. 이어하기 또는 불러오기 버튼
	- 기존 저장 파일의 존재 유무에 따른 버튼 활성/비활성 처리
		ㄴif 저장 파일 존재 X
			a. 버튼 비활성화
		ㄴif 저장 파일 존재 O
			a. 버튼 활성화
				- 클릭 시 마지막 저장 파일 읽기
				- 로딩 화면으로 이동
 d. 게임 종료 버튼
	- 클릭 시 게임 종료 확인 팝업 노출
		ㄴ확인 버튼
			- 자동 저장 진행 X
			- 게임이 종료됨
		ㄴ취소 버튼
			- 클릭 시 게임 종료 확인 팝업 닫힘

 e. 예외 사항
	- 메뉴 선택을 마우스가 아닌 방향키로 지정이 가능한지
	- 불러오기 버튼 활성화 및 클릭 후 저장 파일이 손상되어 있다면 에러코드 팝업 노출
		ㄴ확인 버튼 클릭 시 팝업 닫힘
		ㄴ메인 화면에 잔류
	- ESC로 팝업 닫기(=취소)가 가능한지
	- ESC로 게임 종료가 가능한지

5-1. 새로운 게임(프롤로그 페이지)
 a. 로딩 완료된 후
	- 프롤로그 페이지
		ㄴ컷씬 영상 재생
		ㄴ건너뛰기
			a. 프롤로그 스킵 확인 팝업 노출
				- 줄거리 요약
				- 확인 버튼
					a. 즉시 챕터 선택 화면으로 이동
				- 취소 버튼
					a. 프롤로그 스킵 확인 팝업 닫힘
					b. 프롤로그 이어서 재생
 b. 예외사항
	- 건너뛰기 후 영상 재생이 정확히 멈추는지

5-2. 이어하기 또는 불러오기
 a. 로딩 완료된 후
	- 챕터 선택 화면으로 이동
 b. 예외 사항
	- 마지막으로 저장된 게임 파일이 챕터 오픈에 적용됐는지 확인

6. 로딩 화면
 a. 로딩 아이콘 회전 연출
 b. 예외 사항
	- 리소스가 남는다면 이야기꾼이 책의 페이지를 잡고있는 라이브 연출

7-1. 챕터 선택 화면
 a. 초기 상태 (새로운 게임으로 접근 상태)
	- 1챕터 외 모든 챕터 잠금으로 노출
	- 챕터가 자동으로 선택되어있지 않음
	- 왼쪽 영역의 챕터 정보 노출란이 빈 화면으로 노출
 b. 챕터 리스트
	- 챕터 리스트 별 상태
		ㄴ클리어한 챕터 리스트
			a. 클리어 완료 표시
			b. 챕터 리스트에 마우스 오버 시 빨간 테두리가 나오며 오버 액션
			c. 챕터 리스트 클릭 시 빨간 테두리 노출 유지
			d. 선택된 챕터 리스트의 정보가 화면 좌측에 노출
		ㄴ플레이 가능한 챕터 리스트
			a. 챕터 번호, 챕터 이름, 진행중 표시 노출
			b. 챕터 리스트에 마우스 오버 시 빨간 테두리가 나오며 오버 액션
			c. 챕터 리스트 클릭 시 빨간 테두리 노출 유지
			d. 선택된 챕터 리스트의 정보가 화면 좌측에 노출
		ㄴ 미해금 챕터 리스트
			a. 챕터 리스트 미해금 표시로 노출
			b. 버튼 비활성화로 클릭 불가
			c. 클릭해도 아무 반응 없고 이미 선택된 챕터 리스트가 초기화되지 않음
 c. 입장 버튼
	- 초기 상태 - 비활성화
	- 클리어한 챕터 리스트와 플레이 가능한 챕터 리스트 선택 시 버튼 활성화
		ㄴ 클릭 시 챕터 입장 확인 팝업 노출
			a. 확인 버튼
				- 해당 챕터의 챕터 썸네일 화면으로 이동
			b. 취소 버튼
				- 챕터 입장 확인 팝업 닫힘
				- 챕터 선택 화면에 잔류
				- 선택한 챕터 활성화 유지
 d. 나가기 버튼
	- 현재 게임 진행 상황 저장
	- 메인 화면으로 이동
		ㄴ이 때 새로운 게임으로 진입 후 프롤로그만 보고서 메인 화면으로 나갔을 시, 불러오기 버튼이 활성화

8-1. 게임 화면
 a. 챕터 썸네일 화면
	- 챕터 선택 화면에서 챕터 선택 후 입장 버튼 -> 확인 버튼 클릭 시 접근
	- SPACE 입력으로 게임 화면 전환
		ㄴ챕터 썸네일이 닫힘
		ㄴ인게임 화면이 나옴
 b. 인게임 화면
	- 플레이어 스탯
		ㄴ플레이어 레벨
			a. 현재 플레이어의 레벨 숫자 표시 (예시: 10Lv)
			b. 경험치 게이지 바
				- HP바 좌측끝에 위치
				- 현재 플레이어의 레벨 숫자 표시를 감싸는 원형 테두리로 표시
					ㄴ현재 플레이어의 레벨업에 필요한 최대 요구 경험치 -> 회색
					ㄴ현재 플레이어가 획득한 경험치 -> 노란색
						a. 시계 방향으로 점점 회색 게이지를 노란색 게이지가 채워져감
				- 플레이어의 레벨업
					ㄴ획득한 경험치가 레벨업에 필요한 최대 요구치에 충족되거나 그 이상이면 레벨업
					ㄴ레벨업 시 강조 효과 연출
						a. 경험치 게이지바와 현재 플레이어 레벨이 반짝이는 연출
		ㄴ플레이어 체력
			a. 플레이어의 HP 바
				- 현재 플레이어의 최대 체력 -> 체력 수치보다 어두운 색으로 표시
				- 현재 플레이어의 체력 수치 -> 최대 체력을 꽉 채운 자주 + 핑크색의 그라데이션
				- 체력 감소 시 최대 체력 HP 바를 기준으로 채워져 있는 체력 수치(밝은 색)가 좌측으로 점점 줄어듦
				- 체력 감소(상대로 인한 피격) 시 약한 쉐이크 효과(타격감 및 밋밋한 부분의 해소를 고려)
				- 회복 아이템 사용 시 다시 체력 수치가 회복되며 현재 최대 체력의 어두운 부분을 오른쪽 방면으로 빠르게 채워짐
					ㄴ단, 회복량이 최대 체력을 초과하였을 시 초과된 회복량은 0으로 고정
				- 현재 체력 수치가 최대 체력 비례 20% 이하 시 체력 바가 붉게 깜빡이며 Warning 연출
		ㄴ플레이어 목숨
			a. 플레이어의 목숨 아이콘
				- 플레이어의 HP 바 좌측 상단(겹쳐있다는 뜻이 아님)에 작게 위치해 노출
				- 초기값 -> 3개
					ㄴ단, HP 바 상단에 노출되는 목숨 아이콘은 2개
				- 플레이어의 HP가 0 도달 시 1개가 차감되고 플레이어가 체크포인트에서 부활함
					ㄴ목숨 아이콘이 1개 차감(미노출 처리됨)
					ㄴ즉, 마지막 목숨에서는 목숨 아이콘이 모두 미노출 상태
				- 목숨의 회복 수단은 플레이어가 완전히 사망해 리셋되는 것 외에는 없음
	- 스킬 슬롯
		ㄴ게임 우측 하단에 십자형으로 노출
		ㄴ초기값 -> 기본 스킬이 정해진 위치에 할당된 상태로 시작
			a. 기본 스킬: 매그넘, 기관단총, 스나이퍼
			b. 체력 회복약
			c. 스킬의 위치 변경(키) 가능 (자세한 설명은 '일시정지 - 스킬 페이지'에서 계속)
				- 단, 스킬 슬롯에 할당되어있는 키는 변경 불가. (스킬 슬롯에 할당된 키가 A, S, D면 이 할당된 키 내에서만 스킬을 자유롭게 배치)
			d. 챕터 첫 입장 시, 모든 스킬은 사용 가능 상태(쿨타임X)
		ㄴ스킬과 회복 아이템 공용
			a. 쿨타임
				- 사용된 스킬이나 회복 아이템의 스킬 슬롯(또는 아이템 이미지)이 회색 처리되며 남은 시간이 카운트
					ㄴ해당 스킬 슬롯의 모양대로 회색으로 어둡게 처리가되며 시계 방향으로 회색 처리된 부분이 점점 사라지는 방식
				- 쿨타임 중인 스킬 키 입력 시 무반응
				- 쿨타임이 완료되면 스킬 아이콘 컬러가 강조되며 약간의 펄스 효과
			b. 입력 키 표시
				- 각 스킬 슬롯의 상단(슬롯의 이미지의 상단에 겹쳐짐)에 입력 키가 노출
		ㄴ스킬
		ㄴ회복 아이템
			a. 최대 개수 3개
			b. 회복 아이템의 이미지 오른쪽 하단에 작게 현재 남은 회복 아이템 개수 숫자로 노출
				-단, 변경 가능성 있음 -> 변경 시 적용 내용: 회복 아이템의 이미지에 체력 물약이 채워져있는 물약병이 있고 현재 잔여 횟수를 비례로 물약병의 안에 있는 물약이 점점 줄어든 이미지로 변경
			c. 소진
				- 스킬 아이콘 비활성 노출
				- 키를 눌러도 반응 없음
			d. 리필
				- 플레이어가 완전히 사망해 새로 부활
					ㄴ회복 아이템 모두 리필
				- 플레이어가 목숨이 남아있는 상태에서 사망 후 체크포인트에서 부활
					ㄴ체크포인트에서 저장했을 당시의 남은 회복 아이템 수 만큼만 리필
	- 보스전
		ㄴ보스의 HP가 화면 하단에 노출
			a. 이름, 보스의 HP 바

8-2. 인게임 컷씬 영상
***2026-06-05 - 기획 변경 확정: 기존 인게임 대사창 UI는 영상 컷씬으로 대체
 a. 챕터 진입, 구역을 이동하고 디펜스가 시작되기 직전, 보스전 입장 전에 노출
	- 기존 NPC 대사창, 캐릭터 일러스트, 화자 이름, SPACE 다음 대사 진행 기능은 사용하지 않음
	- 컷씬 영상이 재생됨
	- 영상 재생 중 게임 시간 정지
	- 영상 재생 중 게임플레이 입력 및 컷씬과 무관한 입력은 모두 무시
	- 영상 컷씬 건너뛰기 기능은 유지
		ㄴ영상 재생 중 ESC 입력 시 건너뛰기 확인창 노출
		ㄴ건너뛰기 확인창에는 해당 영상에 맞는 간략한 줄거리 표시
		ㄴ확인 버튼
			a. 건너뛰기 확인창 닫힘
			b. 현재 영상 즉시 종료
			c. 다음 진행 단계로 이동
		ㄴ취소 버튼
			a. 건너뛰기 확인창 닫힘
			b. 현재 영상 이어서 재생
b. 예외사항
	- ESC 입력 후 건너뛰기 확인창이 떠 있는 동안 영상은 일시정지되는지 확인
	- 취소 클릭 시 영상이 중단 지점부터 정확히 이어서 재생되는지 확인
	- 확인 클릭 시 영상 재생이 정확히 멈추고 다음 진행 단계로 넘어가는지 확인
	- 건너뛰기 확인창에 표시되는 줄거리가 현재 재생 중인 영상과 정확히 일치하는지 확인

8-3. 스킬 선택 팝업
 a. 플레이어가 레벨업을 했을 경우 노출
	- 레벨업 효과음 + 시각 효과
	- 게임 화면은 딤드 처리
	- 게임 시간 정지
	- 스킬 선택 팝업 화면 구성
		ㄴ상단 안내 텍스트("레벨업! 강화할 항목을 선택하세요" 같은 안내.)
		ㄴ중앙 보유 스킬 그리드
			a. 1행 - 현재 플레이어가 스킬 슬롯에 '장착한 모든 액티브 스킬'
				- 스킬이 해금되었지만 스킬 슬롯에 장착되어 있지 않는다면 노출되지 않음
			b. 2행 - 모든 패시브 스킬
			c. 스킬 선택 카드
				- 카드 노출 구성
					ㄴ스킬 이름
					ㄴ현재 레벨
					ㄴ다음 레벨 강화 효과 미리보기(스킬 설명 텍스트 및 '현재 레벨 수치' -> '다음 레벨 수치'가 등등)
				- 선택 가능 여부(스킬 레벨업)
					ㄴ3레벨 이상 스킬
						a. 선택할 수 없도록 비활성 처리
						b. 마우스 오버 액션 X
						3. 스킬 레벨에 'MAX' 표시
					ㄴ3레벨 미만 스킬

8-6. 일시정지 - 스킬 페이지
 a. 페이지 배치 구조

			a. 만약 표시할 스킬이 없다면: '장착되지 않은 스킬 없음' 안내를 표시
			b. 만약 표시할 수 있는 스킬이 있다면: '교체 가능 스킬' 안내를 표시
			c. 위 두 표시는 상황에 따라 교체되는 안내 표시
		ㄴ가로로 나열 진행
			a. 정렬된 순서에 무관하게 중간 중간에 스킬을 언제든 빼서 스킬 슬롯에 등록 가능하여야하며, 해당 스킬이 사이에서 빠져있다면 뒤에 나열된 스킬이 앞으로 당겨지며 정렬되어야함
			b. MVP패턴을 이용한 흡사 인벤토리 기능 사용
			c. 만약 표시될 스킬이 많아 좌측 상단 영역을 기준으로 한줄이 초과된다면, 줄바꿈 진행
	- 좌측 하단
		ㄴ현재 장착중인 스킬 슬롯
			a. 게임 화면에서 보여지는 십자형 스킬 슬롯이 그대로 노출

			a. 회복 아이템이 아닌 액티브 스킬 슬롯의 원형 상단 중앙에는 '교체 아이콘'이 표시
		ㄴ액티브 스킬 교체 동작
			a. 액티브 스킬은 보유한 액티브 스킬 아이콘을 드래그해서 등록하는 방식으로 진행
			b. 빈 스킬 슬롯
				- 보유한 액티브 스킬 > 빈 슬롯에 드래그: 빈 슬롯에 드래그한 액티브 스킬 등록
			c. 이미 액티브 스킬 등록된 슬롯
				- 슬롯에 등록된 액티브 스킬 > 스킬 슬롯 영역 밖으로 드래그: 해당 스킬 슬롯이 비워짐 / 드래그된 액티브 스킬은 '보유한 장착 가능한 스킬 인벤토리 영역'으로 이동
				- 1번 슬롯에 등록된 액티브 스킬 > n번 슬롯에 등록된 액티브 스킬에 드래그: 두 스킬이 각자 있던 슬롯에서 서로의 스킬 슬롯으로 위치가 변경됨
				- 보유한 장착 가능한 스킬 인벤토리 영역에서 보유한 액티브 스킬 > 이미 스킬이 등록된 슬롯으로 드래그: 드래그한 스킬이 슬롯에 등록됨 / 이전에 등록되어 있던 스킬은 '보유한 장착 가능한 스킬 인벤토리 영역'으로 이동
				- 1번 슬롯에 등록된 액티브 스킬 > 1번 슬롯으로 드래그: 아무 변화 없음
		ㄴ단, 회복 아이템의 경우 이 모든 동작과 기능을 무시함.

		ㄴ입력 동작 키

			b. 마우스 휠 업, 다운으로 각각 카메라 확대, 축소 가능
		ㄴ우측 하단
			a. 입력 동작 키 가이드 노출
 b. 참고사항
	- 액티브 스킬 드래그: 드래그 중인 스킬 아이콘은 반투명 상태로 마우스를 따라옴.

		ㄴ한마디로 '회복 아이템 슬롯'을 제외한 스킬 슬롯이 강조 표시
